# BarMixHub — учебный проект

Сайт барного интенсива для ручного тестирования методом чёрного ящика.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm. В папке проекта выполните:

```sh
npm ci
npm run build
npm run start:local
```

Откройте http://localhost:4242. Остановка — Ctrl+C.
Для разработки вместо сборки и запуска можно выполнить `npm run dev:local`
и открыть http://localhost:5173.

Локальный сервер не требует `.env`, банковских ключей и внешних сервисов.
Форма обратной связи проверяет данные и подтверждает приём, но не хранит и не отправляет заявки.
Способы оплаты показаны для проверки интерфейса выбора. Создание платежа всегда
возвращает сообщение «Оплата недоступна в локальной учебной версии».
Реальная оплата, статусы платежей и рассылки не входят в область тестирования.
Интернет нужен для установки зависимостей и загрузки внешних фотографий.

Требования для тестировщиков: [TESTING.md](TESTING.md).
Руководство пользователя: [docs/USER_GUIDE.md](docs/USER_GUIDE.md).
Архитектура и схема компонентов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Ответы для авторов: [docs/BUGS.md](docs/BUGS.md) — не передавайте этот файл тестирующим командам.
При передаче проекта исключите `.env`, `node_modules`, `.git` и `server/storage`.
Существующие команды `start` и `dev:full` запускают исходный сервер с интеграциями;
для учебной работы используйте команды с суффиксом `:local`.
