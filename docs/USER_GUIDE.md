# Руководство пользователя BarMixHub

## Начало работы

После запуска приложения по README.md откройте http://localhost:4242.
Регистрация для просмотра сайта и заполнения форм не требуется.

## Просмотр информации

В меню выберите «Интенсив», чтобы прочитать программу, формат, длительность и стоимость обучения.
«О проекте» содержит описание проекта, «Отзывы» — отзывы участников,
«Контакты» — способы связи и форму обращения. Нажатие на логотип открывает главную страницу.
На главной странице нажмите вопрос FAQ, чтобы прочитать ответ; повторное нажатие закрывает ответ.
На узком экране откройте меню кнопкой с тремя полосками; крестик закрывает меню.

## Обратная связь

1. Откройте раздел «Контакты».
2. Укажите имя длиной 2–60 символов, телефон с 10–15 цифрами и корректный email.
3. При необходимости введите сообщение до 800 символов. Допускаются пробелы и несколько строк.
4. Нажмите «Отправить» и дождитесь ответа.
5. При ошибке проверьте поля, исправьте значения и повторите отправку.

При успешном приёме отображается подтверждение, поля очищаются.
Локальная версия не сохраняет обращения и не отправляет их сотрудникам.

## Оформление участия

1. Нажмите «Записаться» или откройте раздел «Оплата».
2. Проверьте выбранный интенсив и его стоимость.
3. Заполните имя, телефон и email. Промокод необязателен; автоматическая скидка в этой версии не предусмотрена.
4. Выберите один способ оплаты: Т-Банк, Яндекс Сплит, Подели или Inpocket.
5. Прочитайте политику конфиденциальности, оферту и три согласия по ссылкам. Они открываются в новой вкладке.
6. Установите все три обязательных флажка и нажмите кнопку продолжения.

В локальной версии появляется сообщение о недоступности оплаты.
Банковская операция не создаётся; вводить данные карты не требуется.

## Переход во внешнюю систему

Кнопка «Войти в систему» предназначена для открытия внешней страницы авторизации в новой вкладке.
Авторизация во внешней системе не входит в локальную версию. Для проверки перехода не нужны учётные данные.

## Завершение работы

Закройте вкладку браузера. Для остановки сервера нажмите Ctrl+C в терминале запуска.
Если сайт не открывается, проверьте, запущен ли сервер и правильно ли указан адрес.
Интернет необходим для установки пакетов и внешних фотографий; банковские ключи не нужны.
